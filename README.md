# Student Performance Analytics System

## About the Project
This project is made using Python, Pandas, and NumPy to analyze student performance. It calculates total marks, averages, grades, and pass/fail results. It also shows class performance, subject-wise averages, and the top 3 students.

## Technologies Used
- Python
- Pandas
- NumPy
- CSV

## Features
- Calculates total and average marks.
- Assigns grades and pass/fail results.
- Finds the class average and highest and lowest student averages.
- Compares subject-wise performance.
- Displays the top 3 students.


## Project Files
- `main.py` – Main Python program where the whole logic is written
- `students.csv` – the file which contain the student data
- `README.md` – this file gives the overall Project information and project overview
- `Project_Documentation.docx` – Detailed project report
